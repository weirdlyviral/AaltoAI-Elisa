# M2 — Anonymisation method

All rules in CLAUDE.md apply. Build Step 1, get tests green, then Step 2.

## Step 1 — config + src/anonymise.py + tests/test_anonymise.py

Add `outputs/releases/` to `.gitignore`.

### config/release.yaml
```yaml
k: 10                        # DISTINCT SUBSCRIBERS per QI group, not rows
time_bucket_minutes: 15      # use the native window if it is coarser
area_mode: enb_tokenised     # enb_tokenised | province
min_subscribers_per_area: 10
rare_category_min_subscribers: 10
numeric_winsorise: [0.01, 0.99]
numeric_round_sig_figs: 3
volume_top_code_quantile: 0.99
aggregate_min_subscribers_per_cell: 10
dp_epsilon: null             # optional Laplace noise on aggregate counts
```
Fill the `treatment` field for every entry in `config/fields.yaml` to match the
transforms below.

### src/anonymise.py
CLI: `python -m src.anonymise --mode {record,session,aggregate,all}` and `--sweep`.

Transforms, applied in order. Each is logged to a transform log entry
(field, action, params, rows_affected):
1. `msisdn`, `imsi`, `imei`, `tac`: drop. (On real data tac would become a device class.)
2. `time_start` → `time_bucket` (floor to `time_bucket_minutes`).
3. `enb` → `area`:
   - enbs with < `min_subscribers_per_area` distinct subscribers → `"<province>_OTHER"`
   - `enb_tokenised`: remaining enbs mapped to random tokens (A0001…) in random
     order; the mapping lives in memory only and is never persisted.
   - `province` mode: area = province.
4. `radio_access_type`, `application_category`: categories with <
   `rare_category_min_subscribers` distinct subscribers → `"OTHER"`.
5. QoE metrics (`tp_*`, `*_rtt_*`, `tcp_retrans_*`, `http_*`): winsorise at the
   configured quantiles, round to N significant figures.
6. Volume fields (`data_GB_sum`, `im_*_GB_sum`, `tethering_data_GB_dl_sum`):
   top-code at the configured quantile, round to N significant figures.
7. k-anonymity for record and session modes. QI = [time_bucket, area,
   radio_access_type, application_category]. For groups with < k DISTINCT
   subscribers: escalate area → province for those rows, recheck, then suppress
   rows still violating. Log escalated and suppressed row counts.

Modes:
- **record**: no subscriber link at all.
- **session**: add `session_id` = HMAC-SHA256(key=os.urandom(32), msisdn),
  truncated to 16 hex chars. The key is never written, logged or returned; delete
  it after use. Session scope = this release (the hour).
- **aggregate**: group by [time_bucket, province, radio_access_type,
  application_category] → n_subscribers, n_rows, median/p10/p90 of each QoE
  metric, sums of volumes. Suppress cells with < `aggregate_min_subscribers_per_cell`.
  If `dp_epsilon` is set, add Laplace noise to counts (seed 42).

Outputs (all via safe writers):
- `outputs/releases/{record,session,aggregate}.parquet`
- `outputs/transform_log.json`
- `outputs/release_stats.json`: rows in/out, % suppressed, % escalated,
  min/median distinct subscribers per QI group, per mode.
- `docs/transformations.md`, generated deterministically from config + transform
  log: table of output column | source column | transformation | parameters |
  rationale | rows affected, plus a "suppressed rows" section.

Final assertions before writing: no identifier columns; min distinct subscribers
per QI group ≥ k; no raw enb values in `area` when tokenised.

### tests/test_anonymise.py (synthetic DataFrame built in the test)
- identifier columns removed
- k holds on distinct subscribers: one subscriber with many rows must NOT satisfy k alone
- rare enb becomes `<province>_OTHER`
- area tokens never equal raw enb values
- the session HMAC key appears in no output or log
- suppression and escalation counts are logged

CHECK: `pytest -q` green; `python -m src.anonymise --mode all` runs;
`python -m src.safety guard --dir outputs` clean.

## Step 2 — parameter sweep
`python -m src.anonymise --sweep`: record mode only, writes no releases.
Grid: time_bucket ∈ {native, 15, 30, 60} × area_mode ∈ {enb_tokenised, province}
× k ∈ {5, 10, 20}. Per combination: % rows suppressed, % rows escalated to
province, number of QI groups, median distinct subscribers per group.
Write `outputs/sweep.json` and print a table.

CHECK: sweep table printed; guard clean. Report which combinations keep
suppression under 5%.
